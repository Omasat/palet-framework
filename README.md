# Palet Framework Core

Palet is a modern, enterprise-ready, strictly typed PHP Framework designed for speed, security, and scalability. It provides robust foundations including Dependency Injection (IoC), PSR-compliant HTTP messaging, flexible Routing, and advanced features like Tenancy and Workflows out of the box.

## Documentation

Full official documentation is available in the [docs/](docs) directory. 
Please start with [Getting Started](docs/01-getting-started.md) to install and configure your first Palet application.

- [01. Getting Started](docs/01-getting-started.md)
- [02. Routing & Controllers](docs/02-routing-and-controllers.md)
- [03. Architecture & IoC Container](docs/03-architecture-and-ioc.md)
- [04. Enterprise Features & Extending](docs/04-enterprise-features.md)

- PHP 8.3 or higher
- Composer
