## ?? About Palet

Palet provides robust foundations including Dependency Injection (IoC), PSR-compliant HTTP messaging, flexible Routing, and advanced features like Tenancy and Workflows out of the box.

*Note: This repository contains the core framework logic. If you want to start a new project, please use the [palet-skeleton](https://github.com/Omasat/palet-app).*
